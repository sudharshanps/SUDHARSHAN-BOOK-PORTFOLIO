## ✨ About the Project

**SUDHARSHAN.IO** is not another conventional developer portfolio.

It is an immersive, interactive digital book experience that brings my professional journey to life through realistic page-flipping animations, modern UI design, interactive components and technology-inspired experiences.

Instead of scrolling through a traditional portfolio website, visitors can explore my journey through an interactive digital publication.

### 🎨 Design Philosophy

- Premium white and light-blue visual identity.
- Royal blue accents and elegant typography.
- Realistic 3D book presentation.
- Cinematic page transitions.
- Smooth micro-interactions.
- Clean, responsive layouts.
- Modern editorial-inspired interface.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/sudharshanps/SUDHARSHAN-BOOK-PORTFOLIO.git
```

### 2. Navigate to the project

```bash
cd SUDHARSHAN-BOOK-PORTFOLIO
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Use the local URL displayed in your terminal.

*Note: These commands assume the project uses npm scripts. Check package.json for the actual scripts.*
